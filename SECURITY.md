# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities in public issues. Use the maintainer contact route listed in the repository profile and include the affected version, platform, reproduction steps, and impact.

We aim to acknowledge reports within 7 days. Do not include passwords, access tokens, private strategy links, or full user data exports.

## Safety boundary

Collaboration and import/export changes must validate untrusted input, preserve user data, and avoid silently contacting third-party services.
